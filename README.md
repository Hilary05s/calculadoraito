# Calculadora Mapache

Calculadora didáctica para alumnos con forma de mapache. Cada operación
muestra en pantalla su **procedimiento** y su **resultado** explicados de
forma sencilla.

## Funciones

- Suma (juntar), resta (quitar), multiplicación (veces), división (repartir) y porcentaje.
- Explicación paso a paso de cada cálculo: sumas y restas por columnas (llevando y pidiendo prestado), multiplicaciones como sumas repetidas o separando en partes, divisiones que muestran de dónde salen los decimales (y cuándo se repiten para siempre), porcentajes, decimales y números negativos.
- Aviso amigable al intentar dividir entre 0.
- Teclas AC (borrar todo) y ⌫ (borrar un dígito).
- Pantalla de tamaño fijo: si la explicación no cabe, las teclas ▲ (subir) y ▼ (bajar) la desplazan, y unas flechitas en la pantalla avisan cuando hay más texto arriba o abajo.

## Uso

Abre `index.html` en el navegador. No necesita instalación.

## Archivos

- `index.html` — estructura de la calculadora.
- `styles.css` — estilos y diseño visual.
- `script.js` — lógica de las operaciones y explicaciones.
